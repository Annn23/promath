Diagram State Machine - Alur Navigasi PROMATH GUI

Keterangan Transisi
: Forward to Next using clickable button
: Backward to Previous using back button
: Backward to Previous using navigation button
📋 Detail State
Klik pada node (lingkaran hijau) untuk melihat detail state dan transisi-transisinya.

🟢 Start

State awal (initial state) saat aplikasi pertama kali dibuka. Ini adalah titik masuk automata.

Transisi keluar:
→ Splash Screen (otomatis / forward)

📱 Splash Screen

Layar pembuka yang menampilkan logo dan branding PROMATH GUI sebelum masuk ke halaman login.

Transisi keluar:
→ Login Page (forward / otomatis setelah beberapa detik)

🔐 Login Page

Halaman login dimana pengguna memasukkan nama atau kredensial untuk mengakses aplikasi.

Transisi keluar:
→ Main Menu (setelah berhasil login / klik tombol MULAI)

🏠 Main Menu

Menu utama yang menjadi hub navigasi ke semua fitur utama aplikasi. Dari sini pengguna dapat mengakses Beranda, Statistik, Ruang Diskusi, dan Akun.

Transisi keluar:
→ Beranda (klik tombol) → Statistik (klik tombol) → Ruang Diskusi (klik tombol) → Akun (klik tombol)
Transisi masuk (dari navigation):
← Beranda ← Statistik ← Ruang Diskusi ← Akun

🏡 Beranda

Halaman beranda yang menampilkan konten utama. Dari sini pengguna dapat mengakses sub-halaman: Materi, Soal, Asesmen, dan Report Belajar.

Transisi keluar (forward):
→ Materi (klik tombol) → Soal (klik tombol) → Asesmen (klik tombol) → Report Belajar (klik tombol)
Transisi keluar (navigation):
← Main Menu
Transisi masuk (back button):
← Materi ← Soal ← Asesmen ← Report Belajar

📊 Statistik

Halaman yang menampilkan data statistik pembelajaran dan progress pengguna.

Transisi keluar (navigation):
← Main Menu

💬 Ruang Diskusi

Halaman forum diskusi dimana pengguna dapat berdiskusi tentang materi pembelajaran dengan pengguna lain.

Transisi keluar (navigation):
← Main Menu

👤 Akun

Halaman pengaturan akun pengguna, termasuk profil, pengaturan, dan preferensi.

Transisi keluar (navigation):
← Main Menu

📚 Materi

Halaman konten materi pembelajaran tentang batik dan matematika. Sub-halaman dari Beranda.

Transisi keluar (back button):
← Beranda

📝 Soal

Halaman kumpulan soal latihan untuk menguji pemahaman materi. Sub-halaman dari Beranda.

Transisi keluar (back button):
← Beranda

📋 Asesmen

Halaman asesmen/ujian untuk mengukur kemampuan pengguna secara formal. Sub-halaman dari Beranda.

Transisi keluar (back button):
← Beranda

📈 Report Belajar

Halaman laporan hasil belajar yang menampilkan ringkasan skor, progres, dan pencapaian pengguna. Sub-halaman dari Beranda.

Transisi keluar (back button):
← Beranda
